# 第一篇论文在中国市场的全面复现计划

## 1. 先明确复现边界

原论文使用金融新闻与股票数据，主要结论是：LLM 文本表示能改善新闻收益预测，并且新闻信息不会立即完全进入价格。中国版本应分成三个层次报告：

1. **严格复现**：使用具有稳定历史覆盖和股票实体关联的授权新闻数据库；
2. **方法复现**：使用中国新闻原文，保持原论文的“文本表示 + 简单预测模型 + 样本外组合”框架；
3. **公开数据原型**：使用 GDELT 等公开元数据验证程序流程，不宣称等价于原论文。

GDELT 适合当前的公开原型：官方资料说明其覆盖全球多语言新闻、持续更新，并提供 DOC/API、事件和 GKG 数据。但 DOC article-list 主要提供标题、URL、来源和时间等元数据，不保证历史正文可批量获得；因此它不能直接替代 RavenPack、Wind、CSMAR 或 Refinitiv 的全文授权数据。

## 2. 数据方案

### 主方案：授权新闻 + 中国行情

- 新闻：RavenPack、Wind、CSMAR、聚源/iFinD 中选一个作为主数据源；
- 行情：与新闻数据口径一致的 A 股日行情；
- 字段：文章 ID、股票实体 ID、发布时间、标题、正文、来源、语言、新闻类型；
- 行情：收盘价/复权价、成交量、市值、行业、停牌、涨跌停、上市/退市日期。

### 当前原型：GDELT

脚本 [src/data/gdelt_news.py](../src/data/gdelt_news.py) 只下载小规模文章元数据，不自动抓取第三方正文。建议先用中国公司、A 股、沪深股票等查询词做 API 可用性和字段审计。因为 GDELT 的股票实体匹配不等于证券数据库的永久实体 ID，需要人工或数据库映射公司名称/股票代码。

### 中国公开来源：东方财富、股吧、雪球

这些来源可以作为第二篇论文中“文本投资者情绪”的公开数据原型，但不应直接当作第一篇论文的新闻数据库：

- 东方财富新闻：更接近财经新闻，但需要验证历史覆盖、发布时间和股票标签；
- 东方财富股吧：适合提取散户评论、标题、发布时间和股票代码；
- 雪球：适合补充投资者讨论，但访问通常有登录、授权、动态渲染或频率限制。

当前实现只接受用户从获得授权的网页/API/数据导出中保存的 CSV/Parquet，不实现绕过登录、验证码、反爬、robots.txt 或访问限制的爬虫。合规接入辅助代码见 [src/data/public_sources.py](../src/data/public_sources.py)，数据规范化见 [src/data/normalize_public.py](../src/data/normalize_public.py)。

建议按以下顺序做小样本：

1. 先从东方财富股吧或雪球的合法导出中获取 1—3 个月、20—50 只股票的帖子；
2. 保存 `post_id`、股票代码、发布时间、标题、正文和匿名化作者哈希；
3. 不保存真实用户名、头像、手机号等个人信息；
4. 统计每只股票每日帖子数、平均长度、重复率和情绪词比例；
5. 与股票收益合并，检验股吧/雪球情绪对未来收益的预测力；
6. 再把论坛情绪作为控制变量或补充信号，与新闻 LLM embedding 区分开。

论坛帖子不是原论文新闻文本的等价替代，最终报告中应分别标记为 `news` 和 `forum_post`，避免把散户评论结果误称为新闻收益预测结果。

## 3. 样本设计

第一版固定如下：

- 市场：沪深 A 股；
- 频率：日频；
- 新闻：标题 + 正文；
- 预测目标：未来 1、5、20 个交易日收益；
- 训练：滚动或扩展窗口，禁止随机切分；
- 组合：五分位预测收益组合和高减低多空组合；
- 训练/验证：先用 2015—2019 训练、2020 验证、2021—2024 样本外；实际日期以数据覆盖为准。

## 4. 实验矩阵

固定同一新闻样本、标签、时间切分和预测模型，仅改变文本表示：

| 实验 | 文本表示 | 目的 |
|---|---|---|
| B0 | 股票特征/过去收益 | 非文本基准 |
| B1 | TF-IDF + Ridge | 词袋基准 |
| B2 | 中文金融词典情绪 | 可解释情绪基准 |
| B3 | Word2Vec | 传统词向量基准 |
| M1 | 中文 BERT | 中文 Transformer |
| M2 | 中文 RoBERTa | 原论文 BERT/RoBERTa 对照 |
| M3 | BGE-M3 | 更强中文/多语言句向量 |
| A1 | Ollama Qwen 辅助情绪/事件字段 | 生成式模型扩展，不作为主 embedding |
| R1 | RavenPack ESS/ENS/Relevance | 商业结构化新闻基准 |

## 5. 文本处理

1. 去除 HTML 和明显模板文本；
2. 保存标题与正文原始版本，清洗版本单独保存；
3. 按文章 ID、股票实体、标题/正文哈希去重；
4. 中文分词只用于词袋/词典模型，Transformer 使用 tokenizer；
5. 正文过长时分块编码再聚合，不静默截断；
6. 每条 embedding 缓存模型名、版本、tokenizer、文本哈希和处理时间。

TF-IDF、词频筛选、Word2Vec 和降维只能在每个训练窗口拟合。预训练 BERT/RoBERTa 可以冻结推理；不能使用全样本文本继续预训练后再宣称样本外结果。

## 6. 新闻时间与收益标签

基本规则：新闻在交易日收盘后或非交易日发布，映射到下一个交易日；第一版统一以该交易日收盘价为入场基准，并计算未来 $h$ 个交易日的收盘到收盘收益：

$$
r_{i,t\rightarrow t+h} = \frac{P_{i,t+h}}{P_{i,t}} - 1.
$$

正式版本应进一步区分收盘前新闻和收盘后新闻，并提供多个对齐口径作为稳健性检验。所有标签都必须由新闻发布时间之后的价格生成。

## 7. 统计与经济评价

### 预测评价

- MSE、MAE、预测值与实现收益相关系数；
- 方向准确率；
- 截面 Rank IC；
- 样本内与严格样本外分别报告；
- Diebold–Mariano 或 block bootstrap 比较预测差异。

### 组合评价

- 五分位组合收益；
- 高减低多空组合；
- 年化收益、波动率、Sharpe、最大回撤；
- 换手率、交易成本后的收益；
- 涨跌停、停牌、T+1、卖空限制后的可实施结果。

## 8. 稳健性和机制

- 标题 vs 正文；
- 新闻新颖度和重复报道；
- 新闻长度、否定词和数字含量；
- 快讯 vs 普通新闻；
- 大盘股/小盘股、高/低流动性；
- 行业、地区和牛熊市场状态；
- 控制规模、价值、动量、反转、波动率、成交量和投资者关注度；
- 加入第二篇论文的股吧情绪和百度指数；
- 加入 RavenPack 结构化情绪变量，检验 LLM 是否提供增量信息；
- 伪发布时间、标签错位和随机文本安慰剂测试。

## 9. 当前执行步骤

1. 用 GDELT API 下载少量中国财经新闻元数据，验证接口和字段；
2. 获取一小段授权新闻全文和对应 A 股行情；
3. 完成数据审计和实体匹配；
4. 运行 TF-IDF + Ridge；
5. 生成预测值和五分位组合；
6. 检查前视偏差；
7. 下载/调用中文 RoBERTa，保持实验条件不变；
8. 加入 BGE-M3、Ollama 和 RavenPack 作为扩展；
9. 最后进行完整样本与稳健性分析。

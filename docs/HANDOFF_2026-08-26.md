项目已经完成从通用论文复现框架到中文个股文本实证平台的主要基础设施：新浪新闻、

## 3. 原始论文与我们的探索

原始论文不是外部口头概括，而是仓库工作区根目录的五份 PDF。完整哈希和映射见
`references/papers_manifest.tsv` 与 `references/paper_to_experiment_map.md`。

最核心的 Chen/Kelly/Xiu 论文明确采用 6 年训练、2 年验证、1 年测试，并说明 LLM
相对简单 NLP 的优势在否定和复杂叙事中更明显。我们保留严格滚动，但把研究问题
从“整个新闻 embedding 是否预测收益”推进到“prompt 的目标 token 是否相对正文提供
可复现增量”。

Yang 的中国市场博士论文促使项目把卖空限制、成本、换手、百度指数和文本情绪的
横截面检验纳入设计。Jiang 等的论文用收益标签训练 BERT，并以 2001--2021 年超过
550 万条新闻报告市场级月度样本外 R2 8.39%；该结果只是方法依据，不能与本项目
个股日频 RankIC 直接比大小。

我们的创新探索按时间形成六层：

1. 完整 prompt pooled embedding 是否预测 next-day/event-3 收益；
2. 从 prompt 中精确提取盈利、收益、超额收益、亏损 span；
3. 公司/代码/日期/时间 mask 是否改变结果并降低身份泄漏；
4. token、body、full pooling 的公平配对；
5. PCA、KMeans 软/硬分层、UMAP+HDBSCAN 是否产生监督增量；
6. 不同模型与不同 prompt 的样本外因子是否可通过线性/树模型融合。

## 4. 已完成的事实结果

### 4.1 四方向 prompt 的新浪结果

旧新浪母面板为 75,894 条，测试年 2018--2026。四方向软聚类共
`4 prompt x 2 models x 2 variants x 9 years = 144` fold，报告记录为 144/144 完成。

代表性样本外排序结果：

| 配置 | 日均 RankIC | 正年份 |
|---|---:|---:|
| 超额收益 / BGE-M3 / short / RankIC 选择 | 0.04439 | 9/9 |
| 收益 / BGE-M3 / short / RankIC 选择 | 0.04327 | 9/9 |
| 亏损 / RoBERTa / short / RankIC 选择 | 0.04317 | 8/9 |
| 收益 / RoBERTa / short / RankIC 选择 | 0.04061 | 9/9 |
| 盈利 / RoBERTa / masked / RankIC 选择 | 0.03920 | 9/9 |

固定 `gamma=0.1`、买卖各 5bp 的代表性成本后结果：

| 目标 | 配置 | 净复利年化 | 净 Sharpe |
|---|---|---:|---:|
| 最佳只做多 | 亏损 / BGE-M3 masked / token 软聚类 | 8.30% | 0.595 |
| 最佳理论多空 | 亏损 / RoBERTa short / token 软聚类 | 4.64% | 0.515 |

这些结果支持“方向 token 存在排序信息”，但不支持“一个 prompt 在所有指标都最好”。
收益 prompt 的跨配置平均 RankIC 最好，超额收益有最高单配置 RankIC，亏损在当前
成本后组合最好。

### 4.2 Mask 的作用

16 个可配对配置中，mask 对成本后只做多 Sharpe 的平均增量为 +0.069，9/16 胜；
对年化收益平均增加 1.15 个百分点。但 `simple_states` IC 平均下降 0.00480，仅
8/16 胜。因此 mask 的首要价值是移除公司身份与时间，不能宣称必然提高预测。

### 4.3 Token 与全文

在新浪 30,946 个共同股票日的旧横向比较中：

| 指标 | RoBERTa | BGE-M3 |
|---|---:|---:|
| 四 prompt body/full 因子平均两两 Spearman | 0.997 | 0.972 |
| 四方向 token 因子平均两两 Spearman | 约 0.653 | 约 0.892 |
| token 与对应 body 的 Top20 重合 | 约 44% | 约 70% |
| masked body/full 平均 RankIC | 约 0.04391 | 约 0.03307 |
| masked word-span 平均 RankIC | 约 0.04010 | 约 0.03154 |

这组事实说明 RoBERTa token 更 prompt-specific，BGE-M3 token 更平滑；不能据此判断
谁“理解得更好”。RoBERTa 盈利、收益、亏损 token 相对对应 body 的多空收益增量约
+9.41、+7.93、+6.89 bp，超额收益是反例，说明 token 的价值可能集中在尾部排序。

### 4.4 Qwen token 尚未整体超过正文

现有 Qwen 新浪线性结果：

| 表示 | PCA32 RankIC |
|---|---:|
| masked article mean | 0.05680 |
| masked 收益 token | 0.05360 |

对应成本后年化为正文 8.57%、token 7.37%。因此当前固定结论是：Qwen token 尚未
整体超过正文池化；软聚类存在局部 token 更强，不足以写成普遍优势。

### 4.5 聚类的边界

KMeans 增量没有跨 prompt 稳定成立。UMAP+HDBSCAN 在 BGE-M3 masked loss 的
同一输入上把股票日多空从 15.26 bp 提高到 20.35 bp，多头从 1.50 bp 提高到
6.17 bp，但仍未超过已有软聚类主配置，且跨年增量不稳定。ARI/silhouette 仅描述
结构，不用于选择收益模型。

### 4.6 巨潮既有 pooled 结果

巨潮全量 pooled embedding 使用 903,665 条公告、RoBERTa/BGE-M3、short 与
masked_short、64 个对齐分片。已有 72 个一级 OOS 回归配置，覆盖 2018--2026。

| 配置 | 平均 RankIC | 正年份 |
|---|---:|---:|
| RoBERTa masked full_mean SmallMLP PCA128 | 0.01764 | 9/9 |
| RoBERTa short body_mean SmallMLP raw | 0.01665 | 7/9 |
| BGE-M3 masked concat Huber raw | 0.01415 | 9/9 |
| BGE-M3 masked full_mean Huber raw | 0.01369 | 9/9 |

这 72 个结果用于预测级树模型的一级因子，不等于当前四 prompt 三模型公平比较。

## 5. 中性六 Prompt embedding 状态

中性 prompt 严格为：估值、确定性、波动率、冲击、流动性、风险，均采用
`分析股票{目标}`，只生成 `masked_short`。每个输出包含 prompt/title/body/full 的
mean/max、CLS 和逐 prompt token embedding。

截至 2026-08-26 主动取消 BGE 数组后的状态：

| 数据集/模型 | 完成 | 状态 |
|---|---:|---|
| 新浪 RoBERTa | 256/256 | 完成 |
| 巨潮 RoBERTa | 255/256 | shard-225 补跑 Job 5031601 等待 Priority |
| 新浪 BGE-M3 | 189/256 | 保留完成结果，67 个运行 task 已取消 |
| 巨潮 BGE-M3 | 78/256 | 保留完成结果，178 个运行 task 已取消 |

BGE 取消前共有 245 个 task、每个 8 CPU，合计 1,960 核。单 task CPU 使用接近
7.8/8 核，但 32GB 内存申请远高于观测到的约 3--4GB。取消不会删除带
`COMPLETED` 的 shard；未完成 task 使用本地临时 stage，没有可保存检查点。

中性六 prompt 目前只适合在已完成 shard 交集做探索，不能声称全量 BGE 已完成，
也不能把不完整 BGE 与完整 RoBERTa 直接按全量行数比较。

## 6. 当前三模型公平比较设计

### 6.1 表示

- RoBERTa/BGE-M3 token：`prompt_token_embeddings` 中精确目标 span 的均值；
- RoBERTa/BGE-M3 body：`body_mean`；
- Qwen token：目标 span 均值，排除句号；
- Qwen body：`article_mean`；
- 不使用 RoBERTa/BGE-M3 `full_mean` 冒充正文；
- 三模型原始维分别为 768/1024/4096，不共享坐标或 PCA 基底。

### 6.2 固定算法

所有 PCA、scaler、KMeans、UMAP、HDBSCAN 只在当前 fold 历史训练数据拟合。

```text
PCA components       32, randomized, random_state=42
Ridge alpha          100
KMeans k             6
KMeans seeds         17, 29, 42, 71, 113
soft shrinkage       500
soft temperature     0.5
UMAP                  8D, n_neighbors=30, min_dist=0.1, cosine
HDBSCAN               min_cluster_size=50, min_samples=10
```

不运行原始维回归，不做 PCA64 稳健性扫描，不按测试年切换参数。聚类方法仍会输出，
但必须与同 PCA32 Ridge 配对，不作为独立无监督任务重复运行。

### 6.3 因子与融合

基础因子共 24 个：3 模型 x 4 prompt x 2 表示。融合包括单模型四 token、单 prompt
三模型、12 token、12 body 和全部 24 因子；逐日横截面标准化后比较等权、Ridge、
ElasticNet 与 HistGradientBoosting。参数固定，验证期只用于训练二级模型/选择最佳
单因子，测试期冻结。

### 6.4 验收假设

只有以下事实同时出现，才支持用户提出的 Qwen 解释：

1. RoBERTa centered cosine 显著低于 BGE-M3；
2. BGE-M3 因子相关和 Top20 重合最高；
3. Qwen 几何更接近 BGE-M3，但因子重合低于 BGE-M3；
4. Qwen 四 token 融合超过 Qwen 最佳单 token 和 Qwen body；
5. 融合增量至少三分之二测试年为正，日期区块 bootstrap 区间不跨 0；
6. 三模型融合继续超过最佳单模型。

若只满足高 embedding 相似度但没有融合增量，应写“表示更平滑”，不能写“产生了
可交易的细粒度信息”。

## 10. 已知风险

1. `simple_states` 多个结果带 `ErrorCode=1002`，异常 `RetTN/SharpeTN` 不能作为净收益。
2. 新浪标签与平台收益曾发现日期/收益定义差异；新闻同池 Top20% 与全市场 RetL 不可横比。
3. Qwen 是因果模型且 prompt 位于正文后，`article_mean` 不受后置 prompt 反向影响；
   RoBERTa/BGE-M3 是双向编码器，结构含义不同。
4. 三模型原始空间维数不同，不能直接对坐标做 cosine；只能模型内比较或比较标准化统计/OOS 因子。
5. 巨潮完整历史为 2010--2026，但 Qwen/四 prompt 最小交集和可用测试年更短；报告必须写实际交集。
6. BGE 中性 embedding 已主动停止，不得把部分 shard 当全量。
7. 当前 submit 脚本使用集群绝对路径；迁移机器时通过环境变量覆盖，不应全局字符串替换。
8. 任务记录本地占约 7.4GB，含代码快照，不进入普通 Git；需要单独归档。
9. 本地 PDF 含受版权限制文献，不进入 GitLab，只有哈希/元数据进入仓库。
10. 待调度 Slurm 任务执行工作区实时代码；提交前记录了快照，但修改核心 runner 后应审计哈希并决定是否重提。
